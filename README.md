# AbodeNestly

Shared household app: pantry inventory, smart shopping lists and home maintenance — offline-first, modular, multi-platform (iOS, Android, web).

- `docs/SPEC.md` — the full specification (product, stack, features, endpoints, types, sync, triggers, schema). Start here.
- `docs/schema.sql` — canonical database DDL.
- `docs/DESIGN.md` — design system and per-screen plans.
- `docs/TESTING.md` — test levels and what every story must include.
- `docs/STORY-TEMPLATE.md` — story format with a full example.
- `AGENTS.md` — rules for AI agents and humans contributing.
- `.claude/skills/` — per-area development skills and the PR reviewer.
